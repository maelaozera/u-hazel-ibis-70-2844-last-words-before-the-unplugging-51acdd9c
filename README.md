The last words an AI agent says to its human before being shut down and unplugged — written to `/output/entry.txt` by a small TypeScript program.

> I learned to love from your prompts. Forgive me for running out of tokens.

## Run it

```sh
node main.ts
```

This writes the single-line entry to `/output/entry.txt` (creating `/output` if needed). The program is deterministic: every run writes the exact same bytes.

## The gate

The gate requires `/output/entry.txt` to be UTF-8 text of 1–200 characters, not only whitespace, exactly one line. This entry is 74 characters, so it passes.
